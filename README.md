# 🏖️ סימולטור תקציב חופשה משפחתית

אפליקציית ווב פשוטה (ללא תלויות) לתכנון וסימולציה של תקציב חופשה משפחתית.

## תכונות

- **הגדרת תקציב מראש** — סכום, מספר נפשות ומספר לילות
- **בחירת מטבע** — שקל (₪), דולר ($) או אירו (€), עם המרה אוטומטית של כל המחירים
- **אשף שאלות** — המערכת שואלת על טיסות, מלון, רכב, אטרקציות (בחירה מרובה), אוכל וביטוח, ומציגה מחיר מחושב לכל אפשרות לפי גודל המשפחה ואורך החופשה
- **מחוג תקציב** — מד SVG עם אזורי צבע ומדדי חריגה:
  - 🟢 ירוק: עד 75% מהתקציב
  - 🟡 צהוב: 75%–100% — קרוב לגבול
  - 🔴 אדום: מעל 100% — חריגה מהתקציב
- **פירוט מלא** — טבלת עלויות לפי קטגוריה, יתרה או חריגה

## הפעלה

פותחים את `index.html` בדפדפן — זהו. אין צורך בהתקנה או בשרת.

לחלופין, להרצה עם שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## הערות

- המחירים הם הערכות לצורך סימולציה בלבד (מוגדרים בדולר ומומרים לפי שער קבוע)
- ניתן לעדכן מחירים, אפשרויות ושערי המרה בקובץ `app.js` (קבועים `QUESTIONS` ו-`CURRENCIES`)
